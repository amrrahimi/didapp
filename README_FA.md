# دیده‌بان · نرم‌افزار دسکتاپ معامله‌گر رمزارز (ویندوز و مک)

امکانات: قیمت زنده از صرافی · تحلیل با استراتژی‌های تریدینگ‌ویو · ربات خرید/فروش · **حساب مجازی** · **مارجین و فیوچرز (لانگ/شورت، اهرم)** · **بک‌تست چندتایم‌فریم با ماتریس وین‌ریت روی چارت**

---

## بخش اول: تبدیل به فایل نصبی (exe و dmg)

### ✅ روش پیشنهادی: ساخت خودکار با GitHub (بدون نصب چیزی روی سیستم)
این روش هم برای ویندوز و هم مک کار می‌کند، و نیازی به کامپیوتر مک یا ویندوز ندارید.

**قدم ۱: ساخت حساب و مخزن**
1. به https://github.com بروید و حساب رایگان بسازید.
2. دکمه‌ی **+** (بالا سمت راست) → **New repository**.
3. اسم بدهید: `didban`. گزینه‌ی **Private** را انتخاب کنید (کد خصوصی بماند). **Create repository** را بزنید.

**قدم ۲: آپلود فایل‌ها**
1. فایل زیپ `Didban-Desktop-Source.zip` را روی سیستم خودتان **Extract** (استخراج) کنید.
2. در صفحه‌ی مخزن، لینک **uploading an existing file** را بزنید.
3. همه‌ی فایل‌ها و پوشه‌های داخل پوشه‌ی استخراج‌شده را بکشید و رها کنید (drag & drop). **پوشه‌ی `.github` را هم حتماً بکشید**؛ در ویندوز و مک به‌صورت پیش‌فرض مخفی است؛ اگر پوشه‌ی `.github` در کامپیوترتان دیده نمی‌شود،  در GitHub، دکمه‌ی **Add file → Create new file** را بزنید، نام فایل را `.github/workflows/build.yml` بگذارید و محتوای فایل داخل زیپ را کپی کنید.
4. پایین صفحه **Commit changes** را بزنید.

**قدم ۳: ساخت فایل‌ها**
1. بالای مخزن، تب **Actions** را بزنید. اگه پیغام فعال‌سازی آمد، **I understand, enable** را بزنید.
2. از ستون چپ **Build Didban (exe + dmg)** را انتخاب کنید.
3. دکمه‌ی **Run workflow** → دوباره **Run workflow** (سبز).
4. حدود ۱۰ تا ۱۵ دقیقه صبر کنید تا علامت سبز ✅ بیاید.

**قدم ۴: دانلود**
1. روی همان اجرا کلیک کنید. پایین صفحه بخش **Artifacts** است:
   - `Didban-Windows` → فایل `Didban.exe` برای ویندوز
   - `Didban-macOS-AppleSilicon` → فایل dmg برای مک با چیپ M1/M2/M3/M4
   - `Didban-macOS-Intel` → فایل dmg برای مک‌های اینتل قدیمی
2. روی هر کدام بزنید تا زیپ دانلود شود، بعد آن را باز کنید.

> **مک چه نوعی دارم؟** از منوی سمت چپ بالا (لوگوی سیب) → About This Mac. اگه نوشته **Apple M...** باشد، AppleSilicon؛ اگه **Intel** باشد، Intel.

**قدم ۵: انتشار نسخه (اختیاری، برای لینک دائمی)**
اگر تگ بزنید، فایل‌ها خودکار در بخش **Releases** منتشر می‌شوند:
در صفحه‌ی مخزن، روی **Create a new release** → در بخش Tag بنویسید `v1.0.0` و **Create new tag** → **Publish release**. بعد از ۱۵ دقیقه فایل‌ها آنجا هستند.

### راه دستی (اگه خودتان کامپیوتر دارید)
- **ویندوز:** Python 3.11 را از python.org نصب کنید (حتماً تیک *Add Python to PATH* را بزنید). بعد پوشه را باز کنید و روی `build_windows.bat` دوبار کلیک کنید. فایل خروجی: `dist\Didban.exe`
- **مک:** برنامه‌ی Terminal را باز کنید، `cd` به پوشه‌ی پروژه، و بنویسید: `chmod +x build_mac.sh && ./build_mac.sh`. فایل خروجی: `dist/Didban.dmg`
- **اجرای بدون ساخت (تست):** `python -m pip install -r requirements.txt` و بعد `python run_dev.py`

### باز کردن فایل ساخته‌شده (هشدار امنیتی)
فایل‌ها امضای دیجیتال رسمی ندارند، پس سیستم هشدار می‌دهد. این طبیعی است.
- **ویندوز:** روی *More info* بزنید → *Run anyway*.
- **مک:** فایل dmg را باز کنید، `Didban` را به پوشه‌ی **Applications** بکشید. بار اول روی آن **راست‌کلیک → Open** بزنید و دوباره Open را بزنید. اگه باز نشد: System Settings → Privacy & Security → پایین صفحه **Open Anyway**.

## بخش دوم: راهنمای استفاده

### ۱. حساب مجازی (تمرین با پول فرضی)
- پیش‌فرض برنامه همیشه **حساب مجازی** است: قیمت‌ها واقعی‌اند، پول فرضی.
- تب **حساب مجازی**: موجودی شروع (۱۰۰، ۱۰۰۰ یا ۱۰۰۰۰ تتر) را انتخاب کنید و **شروع دوباره** را بزنید.
- تمام معاملات (ربات، دستی، لانگ، شورت، مارجین، فیوچرز) همان‌جا ثبت و منحنی سرمایه و وین‌ریت محاسبه می‌شود.
- **پیشنهاد:** حداقل دو هفته فقط با حساب مجازی کار کنید.

### ۲. اتصال به صرافی (فقط برای قیمت یا معامله‌ی واقعی)
- دکمه‌ی **اتصال به صرافی** → صرافی را انتخاب کنید.
- بدون کلید هم می‌توانید از **فقط قیمت + حساب مجازی** استفاده کنید.
- برای کلید API: در پنل صرافی فقط **Read** و **Trade** (اسپات/فیوچرز/مارجین طبق نیاز) را فعال کنید. **هرگز Withdraw (برداشت) را فعال نکنید.** اگر صرافی امکانش را دارد، کلید را به IP خودتان محدود کنید.
- کلیدها فقط در **Keychain** (مک) یا **Credential Manager** (ویندوز) روی همین سیستم ذخیره می‌شوند.

### ۳. انتخاب بازار و اهرم
بالای برنامه: **اسپات** (خرید واقعی سکه، فقط لانگ) · **مارجین** (قرض‌گرفتن برای لانگ/شورت) · **فیوچرز** (قرارداد دائمی USDT، لانگ/شورت با اهرم تا ۵۰x).
- اهرم را انتخاب و **اعمال** را بزنید.
- فیوچرز را با اهرم کم (۲ تا ۳x) شروع کنید. با اهرم ۱۰x، حرکت حدود ۱۰٪ خلاف جهت کل مارجین را می‌سوزاند.
- **ایزوله** یعنی ضرر فقط همان پوزیشن؛ **کراس** یعنی کل موجودی پشت پوزیشن است. مبتدی‌ها ایزوله.

### ۴. تحلیل زنده و ربات
- بالا: **بلندمدت**، **کوتاه‌مدت**، **نوسان‌گیری** را انتخاب کنید.
- ارزهای منتخب را با ★ مشخص کنید (ربات فقط همین‌ها را می‌بیند). جستجو با نام فارسی یا نماد (مثلاً `سولانا` یا `SUI`).
- کارت **نظر عامل** با درصد اطمینان و وین‌ریت هر استراتژی.
- دکمه **شروع ربات**: ربات طبق سیگنال و تنظیمات ریسک خرید/فروش می‌کند و حد ضرر/سود را خودش پایش می‌کند.
- **لانگ دستی / شورت دستی** برای ورود دستی.

### ۵. مدیریت ریسک (تب آخر)
- **مارجین هر معامله**: مثلاً ۵٪ از موجودی.
- **سقف ضرر روزانه**: اگر امروز این مقدار ضرر شد، ربات تا فردا پوزیشن جدید نمی‌زند.
- **حداقل اطمینان**: کمتر از این، ورود نمی‌کند.

### ۶. بک‌تست و وین‌ریت (تب دوم)
1. ارز را انتخاب کنید (مثلاً `BTC/USDT`).
2. تایم‌فریم‌ها را تیک بزنید (مثلاً ۱۵ دقیقه، ۱ ساعت، ۴ ساعت، روزانه).
3. استراتژی‌ها را تیک بزنید؛ **عامل ترکیبی** یعنی همه‌ی استراتژی‌های حالت فعلی با هم.
4. **اجرای بک‌تست** را بزنید. برنامه کندل‌های واقعی صرافی را می‌گیرد و معاملات گذشته را شبیه‌سازی می‌کند.
5. **ماتریس وین‌ریت**: هر ردیف یک استراتژی، هر ستون یک تایم‌فریم. رنگ‌ها: سبز = وین‌ریت بالا.
6. روی هر خانه کلیک کنید تا معاملاتش روی چارت بیاید: ▲ ورود لانگ، ▼ ورود شورت، ● خروج با سود، ✕ خروج با ضرر. پایین هم منحنی سرمایه‌ی هر استراتژی.

> **بک‌تست با تاریخچه‌ی گذشته است؛ نتیجه‌ی آینده را تضمین نمی‌کند.** اگر یک استراتژی روی ۱۰۰۰ کندل خوب بود ولی روی تایم‌فریم‌های دیگر نه، احتمالاً فقط شانس بوده. تعداد معاملات کم (زیر ۳۰) را جدی نگیرید.

## بخش سوم: نکات امنیتی و ریسک
- **هیچ استراتژی‌ای سود تضمینی ندارد.** فیوچرز با اهرم می‌تواند کل پولتان را از دست بدهد.
- ربات و حد ضرر فقط وقتی کار می‌کنند که برنامه باز و اینترنت وصل باشد. برای امنیت بیشتر، حد ضرر را روی خود صرافی هم بگذارید.
- اول حساب مجازی، بعد معامله‌ی واقعی با مبلغ کم.
- برای مالیات و قوانین ایران یا کشورتان، با متخصص مشورت کنید.
- این نرم‌افزار توصیه‌ی مالی نیست.

|---|---|
| `main.py` / `run_dev.py` | نقطه‌ی شروع برنامه |

| `didban/ui.py` | رابط کاربری فارسی |
| `didban/storage.py` | ذخیره‌ی تنظیمات و تاریخچه در پوشه‌ی `~/.didban` |
